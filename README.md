# レシピ検索システム（DBなし版）

システム開発講座2026 応用編の課題です。
買い物中に、**カートに入れた商品**と**家にある食材**から作れるレシピを探すWebアプリです。

この版はデータベースを使わず、HTML・CSS・JavaScript だけで動きます。
マスタデータ（食材・レシピ）は `js/data.js` に JavaScript の配列として入っています。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK）
2. 「カート内食材」「カート外食材（家にある食材）」「対象外食材」に、ドロップダウンで食材を選んで「追加」する
3. 「レシピを探す」を押すと、一致する食材が多い順にレシピが表示される
4. レシピをダブルクリックすると詳細（材料・作り方）が表示される

- 一覧の食材をダブルクリック → 確認 → OK で削除できます
- **対象外食材を材料に含むレシピは表示されません**

## 検索の考え方

```
検索対象食材 ＝ カート内食材 ∪ カート外食材（重複は1つ）
除外レシピ   ＝ 材料に対象外食材を1つでも含むレシピ
一致数       ＝ レシピの材料のうち、検索対象食材に含まれる数
```

一致数が1以上のレシピを、一致数の多い順 → 不足食材の少ない順 → レシピIDの順に表示します。

## ファイル構成

```
recipe-search/
├── index.html        画面（メイン画面・レシピ詳細画面）
├── css/style.css     デザイン・スマートフォン対応
├── js/data.js        マスタデータ（カテゴリ9件・食材50件・レシピ15件）
├── js/main.js        画面の処理（追加・削除・検索・画面切替）
├── images/           レシピ画像（r001.jpg〜r015.jpg を置く。ない時は noimage.png）
└── docs/仕様書.md     仕様書
```

## 使用技術

HTML / CSS / JavaScript（ライブラリ・サーバー・データベースは不使用）
