# レシピ検索システム（DB版：PHP + MySQL）

システム開発講座2026 応用編の課題です。
買い物中に、**カートに入れた商品**と**家にある食材**から作れるレシピを探すWebアプリです。

DBなし版（[recipe-nodb](https://github.com/imaccho/recipe-nodb)）を、
PHPでMySQLのデータを読む形に作り変えたものです。

## 使い方

1. 「カート内商品」で商品を、「カート外食材」「対象外食材」で食材を選んで「追加」する
2. 「レシピを探す」を押すと、一致する食材が多い順にレシピが表示される
3. レシピをダブルクリックすると詳細（材料・分量）が表示される

- 一覧の項目をダブルクリック → 確認 → OK で削除できます
- **対象外食材を材料に含むレシピは表示されません**
- 金額の計算と作り方（手順）の表示は、今回は保留しています

## サーバーに置く手順

1. `config.sample.php` をコピーして `config.php` を作り、データベースの接続情報を書く
   （`config.php` にはパスワードが入るため、GitHubには上げない設定にしています）
2. ファイル一式をサーバーの公開フォルダにアップロードする
3. ブラウザで `index.html` を開く

PHPは、データベースに接続できるサーバー（ふつうはDBと同じレンタルサーバー）に置いてください。
`index.html` をダブルクリックで開く方法（file://）では、PHPが動きません。

## データベース

テーブルは設計書（DB設計_テーブル設計）のとおり、次の4つです。

| テーブル | 内容 |
|---|---|
| ms_products | 商品マスタ |
| foods | 商品と食材（F001など）の紐付け |
| recipes | レシピ |
| materials | レシピの材料 |

`sql/` の2つのファイルは、ローカルで動作確認するための**テスト用DB**です（本番DBとは別）。
詳しくは `docs/仕様書.md` の13章を参照してください。

## ファイル構成

```
recipe-search/
├── index.html            画面（メイン画面・レシピ詳細画面）
├── css/style.css         デザイン・スマートフォン対応
├── js/main.js            画面の処理（api のPHPを fetch で呼ぶ）
├── api/
│   ├── db.php            接続と共通処理
│   ├── get_products.php  商品一覧
│   ├── get_foods.php     食材一覧（レシピの材料から重複なしで取得）
│   ├── search_recipes.php レシピ検索
│   └── get_recipe.php    レシピ詳細
├── config.sample.php     接続設定の見本
├── image_paths/          レシピ画像（r001.jpg〜r015.jpg、noimage.png）
├── sql/                  テスト用DB
└── docs/仕様書.md         仕様書（13章がDB版）
```

## 使用技術

HTML / CSS / JavaScript、PHP 8、MySQL（utf8mb4）
